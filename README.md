## 🚀 Шаг 1: Запуск
cd hotel-booking
docker-compose up --build

## Шаг 2: Проверьте работу
Откройте в браузере:
http://localhost:8000 → увидите JSON с приветствием
http://localhost:8000/health → {"status":"ok","service":"Hotel Booking API"}
http://localhost:8000/docs → интерактивная документация FastAPI 

## Если порт 8000 занят
→ Измените порт в docker-compose.yml:
ports:
  - "8001:8000"  # теперь доступно на http://localhost:8001
## Остановка проэкта
docker-compose down

## План:
Работает FastAPI в Docker. Теперь можно добавлять:
Базу данных PostgreSQL (второй сервис в docker-compose)
Модели SQLAlchemy

# Система управления бронированием
Описание: приложение для бронирования номеров в отелях.
Основные функции:
• Поиск доступных вариантов бронирования с возможностью
фильтрации по дате, локации и стоимости.
• Страница с детальной информацией о бронировании.
• Система авторизации и сохранение списка бронирований
пользователя.
• Оформление бронирования с функцией подтверждения.
ИИ-функции:
• Создать рекомендательную систему с альтернативнми вариантами
на основе характера просмотров объектов пользователей.
Дополнительные функции:
• Реализовать также личный кабинет управляющего.
Требования к бэкенду:
1. Разработать модель данных для реализации основных функций
проекта. Минимальный набор таблиц:
• бронирование: идентификатор, название, дата, локация, цена,
описание, статус подтверждения.
2. Разработать модель данных для работы сервиса регистрации,
авторизации и аутентификации пользователей: идентификатор, имя,
фамилия, логин, пароль.
3. Разработать API для регистрации, авторизации и аутентификации.
Эндпойнты: регистрация, аутентификация, смена пароля, обновление
токена.
4. Разработать API для работы основных функций бронирования:
создание, удаление, редактирование, чтение (пагинация и фильтры).
Результат реализации бэкенда:
1. Разработана модель данных и настроены миграции.
2. Создан API для работы с основными функциями. Код запускается и
выполняет требования задания. Допускается и приветствуется любое
расширение, дополнение и обоснованное улучшение функционала.
3. Разработан набор тестов для проверки всех эндпойнтов API.
4. Развёртывание: создан файл конфигурации Docker Compose для
сборки и запуска проекта в контейнере.
